# Agent emblems

One SVG per agent, 256×256, generated from a shared frame so the roster reads
as one team: a rounded tile with a two-tone gradient per agent, a sigil in the
same off-white ink and stroke width, and one accent colour where the sigil
needs a focal point. Each sigil depicts how the agent thinks, never a face:
the generalist's loop, the architect's arch and keystone, qa's lens over a
forking path, dba's cylinder with a key inside.

They are for humans: README, REFERENCE.es.md, slides, a host that shows an
avatar. Nothing in the catalog's install path reads them, and `validate.py`
does not check them. To change one, edit the SVG by hand; the files are
small and self-contained (no fonts, no external references).
